
# Job Application Tracker

A full-stack web application to manage and track job applications throughout the placement and job-hunting process.

## Tech Stack

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- HTML, CSS, JavaScript
- React (planned)
- Node.js (planned)

## Current Features

- Flask application and REST API
- Retrieve job applications
- Add job applications
- Basic input validation
